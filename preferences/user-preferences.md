# 用户长期偏好

只记录用户明确要求跨视频、跨项目持续沿用的偏好。单个视频的角色气质、镜头时间、动作和修订结论不得写入此处。

## 工作流偏好

- 每次收到反馈时，明确区分 `PROJECT_LOCAL`、`USER_PREFERENCE` 和 `SKILL_GENERAL`。
- 单视频内容只保留在对应项目的校准记录，不为记录而重复建档。
- 个人偏好放在 `preferences/` 目录，与通用 Skill 规则分开。
- 有直接证据、可跨视频复用的通用知识应升级到最窄的 Skill reference，并完成校验。

## 尚未确认的审美偏好

- 暂无。当前“女剑士应有运筹帷幄感”只适用于正在复刻的视频，不视为跨项目偏好。
