# 打戏与高密度动作分析

用于拳脚、兵器、枪战、追逐、跑酷、群战或任何动作密集片段。目标不是给招式命名，而是恢复可见的受力、轨迹、反应、空间与衔接。

## Combat Beat

把每次有效交互记为：

```text
进攻者起始状态
→ 蓄力/准备
→ 发力来源
→ 身体和武器轨迹
→ 防守者动作
→ 命中/格挡/擦过/落空/抓取/碰撞/未知
→ 双方身体反馈
→ 位移与重心变化
→ 恢复
→ 下一动作接口
```

关键字段：时间、发起者、目标、起止站位、朝向、前后脚、左右手（仅证据明确时）、攻击方向、接触类型、反应、环境反馈、镜头反馈和置信度。

## 坐标与状态

每个 beat 更新简单坐标：左/中/右，前/中/后景，面向与移动方向，两人距离。跨镜头默认维持屏幕方向；如换轴，指出是环绕越轴、反打还是有意重置。

当复刻结果依赖精确构图、极端透视、肢体轮廓或定格姿态时，升级为屏幕空间记录：关键点的 `x% / y%`、主体高度占比、两人相对尺度、肢体端点、轴线相对水平线的角度，以及以关节为顶点的夹角。角度只写可见证据支持的近似值或区间；透视遮挡严重时保留轮廓和端点，不强行恢复三维姿态。

兵器持续跟踪：所有者、持握手、方向、位置、完好状态。除非画面证明，不允许无解释换手、消失或形态变化。

## 身体力学

只有连续画面明确支持时，才用可见线索说明力量从哪里来：蹬地、落脚固定、屈膝、重心转移、转髋、扭腰、肩带动、前序动量延续。不要用“猛烈、快速、震撼”替代力学，也不要用常见招式知识补全画面没有证明的屈伸或旋转。

每个关键动作先分两栏：

- **固定锚点：** 画面位置和尺度基本不变的头、肩、躯干、支撑点或道具。
- **变化区域：** 当前唯一主要运动的肢体、轮廓、物体或接触关系。

若多种动作机制都能产生同一可见结果，提示词只写固定锚点与变化区域的屏幕结果。例如写“头肩保持右上，前景腿部轮廓沿下半画面连续铺开”，不要擅自选择“伸膝”或“转髋”。

描述攻击轨迹：直线前刺、水平弧线、斜向下劈、斜向上挑、纵向下砸、旋转横扫、侧向踢击、上升或下降轨迹。证据不清时写“一侧手臂/腿”，不要猜左右。

接触必须分类：

- `CLEAN_HIT`：清晰命中并有同步反馈。
- `PARTIAL_HIT / GRAZED`：局部接触或擦过。
- `BLOCKED / PARRIED`：阻挡或改变轨迹。
- `MISSED`：攻击落空。
- `GRABBED / COLLISION`：抓取或身体/武器碰撞。
- `UNKNOWN`：遮挡或抽帧不足，继续加密取证。

## 接触五阶段

重击、摔投、武器咬合和击飞不能只写“命中后飞走”。按证据分开记录：

1. **预接触间隙：** 双方尚未接触时的距离、站位和逼近轨迹。
2. **首次接触：** 接触部位、画面位置和确切先后；先看见接触点。
3. **压缩：** 受击部位、躯干、武器或地面的局部形变与重心变化。
4. **保持接触：** 力量是否持续传递、双方是否仍贴近，以及持续时间。
5. **释放/分离：** 何时脱离、沿什么方向移动、怎样落地或恢复。

受击者不得在首次接触前提前后仰、起飞或倒地。原片若存在明显的接触保持，必须写明保持到何时，再释放击飞；不要把接触、压缩和分离压成同一瞬间。

## 反馈与动量

每次重大接触检查四层：

1. 目标身体：头、躯干、髋、脚步、失衡、滑动、旋转或跌落。
2. 发起者：随挥、姿态打开、重心前移或旋转延续。
3. 材质/环境：衣发、武器震动、尘土、水花、碎片、墙面或地面反应。
4. 摄影机：短促微震、推近、甩镜、重构图或前景运动模糊。

动量不能凭空消失。落空后若身体继续旋转，应把剩余旋转转成下一记肘击、回身或失衡恢复；命中后双方都要有合理的随挥和受力结果。

## 并行与组合

明确区分：

- `SEQUENTIAL`：A 完成后 B 才开始。
- `SIMULTANEOUS`：A 与 B 同时动作。
- `OVERLAPPING`：B 在 A 尚未结束时启动。

把 jab→cross、格挡→反击、闪避→反击、抓取→破坏平衡→摔落、起跳→空中动作→落地等写成一个组合链，而不是无关动词列表。

追逐额外跟踪追逐者、目标、距离是缩短/稳定/扩大、障碍路线与摄影机路线。跑酷额外跟踪助跑、起跳、支撑点、身体轨迹、落地脚与落地后的动量延续。

## 节奏与镜头

标记实时、慢动作、速度坡度或定格。用动作段表达节奏，例如 `连续快攻 → 半拍停顿 → 突然反击 → 命中恢复`。

常用镜头链应服从参考：建立空间的全景 → 交手中景跟拍 → 接触近景/反打 → 重新建立空间。参考是长镜头时不得为了“更刺激”擅自多切。

重要姿态除终点外还记录：姿态何时到达、保持多少秒或多少帧、保持期间哪些部位必须锁定，以及哪些次级元素仍可运动。头发、衣摆、烟尘可以衰减，不代表核心姿态继续变化。

## 压缩到提示词

优先级：

1. 主动作、方向、接触类型、反应、时间和运镜。
2. 发力机制、环境反馈和连续性。
3. 次要装饰动作。

最终提示词必须让人能回答：谁先动、沿什么方向、另一方如何应对、是否接触、受力后移到哪里、剩余动量怎样接下一动作。任何一项无法回答且又影响结果时，回到该时间窗加密抽帧。

若问题是“画面长得不像”而不是“动作因果不通”，优先补坐标、占比、角度、固定锚点和终态保持，不要继续增加招式名或力学解释。
