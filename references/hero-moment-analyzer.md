# 高光时刻分析

用于登场、变身、觉醒、蓄力、绝招、反杀、揭示、情绪爆发和英雄定格。目标不是只描述最终特效，而是恢复高光如何被铺垫、释放并收束。

## 高光弧线

按证据选择适用阶段：

```text
SETUP
→ ANTICIPATION
→ HOLD
→ MICRO DETAIL
→ ENVIRONMENT RESPONSE
→ ENERGY / EMOTION BUILD
→ RELEASE
→ SCALE EXPANSION
→ REACTION
→ AFTERMATH
→ HERO FRAME
```

不是每段都必须齐全。关键是找出峰值时间，以及峰值之前的预期与之后的余波。

## 铺垫与停顿

检查：主体是否突然停下、镜头是否减速或推进、声音是否降低、视线/手部/脚步是否变化、衣发与尘粒是否先响应、敌人是否停顿。把真正可见的 `0.2–1 秒` 保持写成“短暂停顿/保持半拍”，不要把整段误写成慢动作。

常见尺度对比：眼睛/手/武器/脚的极近细节 → 全身 → 大全景。微观镜头的作用是积累预期，宏观镜头的作用是兑现规模；提示词要保留这个先后。

## 变身与能量逻辑

变身按 `常态 → 触发 → 首个变化 → 扩散 → 环境响应 → 完成形态 → 揭示` 跟踪。记录眼睛、头发、服装、体表、护甲、光效和环境分别何时变化。参考不是硬切替换时，不要把渐变编译成瞬间换装。

能量按 `起点 → 流向 → 汇聚 → 压缩/增强 → 释放方向 → 与目标/环境交互 → 残留` 描述。若起点或流向不可见，保留未知；不要用“全身爆发强大能量”掩盖缺失的运动逻辑。

绝招额外跟踪：姿势、蓄力、瞄准、释放、传播轨迹、碰撞点、扩张范围、次级影响和余波。

## 登场与揭示

恢复真实揭示顺序，例如：环境声 → 影子 → 脚步 → 局部轮廓 → 面部 → 全身，或他人反应 → 镜头转向 → 人物出现。参考通过悬念延迟露脸时，不提前展示全貌。

## 反应与英雄帧

高光的尺度常由他人和环境反应证明。记录敌人、群众、建筑、云层、尘土或水面的同步变化。峰值后识别最值得锁定的构图：低机位全身、逆光剪影、烟尘中心、武器占前景、缓慢环绕或静止姿态。

## 声音动态

标记音乐上升、低频累积、声场抽空、短暂静默、心跳/能量声、释放瞬态、混响与余震。声音和画面峰值必须对齐；没有音轨或听不清时不要编造具体音色。

## 细节预算

把最多描述预算给最高峰及其直接铺垫。一个 10 秒片段可将约 40% 的动作细节放在高潮窗口，而不是每秒平均分配。背景装饰不能挤掉触发、释放、反应与英雄帧。

## 质量门

确认：峰值时间明确；峰值前有可见预期；环境在峰值前后有物理响应；景别或空间规模发生有意义的变化；声音对比被保留；高潮后有余波或稳定结束态；提示词解释了高光为何成立，而不只是贴上“史诗、震撼”的标签。
