# 大场面分析

用于巨型生物、军团、城市毁坏、灾害、爆炸、巨型法术和多层空间事件。大场面不是“更大的形容词”，而是可读的尺度参照、空间层次和连锁反应。

## 建立尺度

至少选择两个可靠尺度参照，并按深度组织：

```text
前景锚点（人物、车辆、碎片）
→ 中景活动（队伍、街区、战斗群）
→ 背景结构（城墙、建筑群、山体）
→ 极远景主体（巨物、天象、冲击范围）
```

说明遮挡、相对尺寸和摄影机如何揭示尺度。不要凭空写精确米数；优先使用“数倍于城墙”“横跨画面”“由云层后显现”等可见关系。

## 群体运动

将群体视为有方向和密度变化的系统：从哪里进入、朝哪里流动、前中后排速度是否一致、是否分流/拥堵/溃散、局部反应如何传播。避免把每个人写成相同同步动作。

## 事件传播

按因果恢复宏观事件：

```text
触发点
→ 第一层局部变化
→ 冲击/能量/坍塌传播方向
→ 接触的结构与群体反应
→ 次级碎裂、尘云、水浪或光照变化
→ 余波和最终空间状态
```

爆炸、坍塌和法术要区分发源、传播、碰撞、扩张和残留。环境反馈应有时间差：近处先动，远处后动；重物慢、轻尘快。

## 摄影机与可读性

大场面优先保持一个清楚的空间锚点。后拉、升高、横移或环绕必须服务于“揭示规模”或“追踪传播”，不要同时堆叠多个无目的运镜。切到近景时保留能回到全景的方向和位置线索。

## 气氛与光

记录雾、烟、雨、云、逆光、体积光和大范围闪光对远近层次的影响。光源变化若来自爆发，说明照亮顺序、阴影变化与衰减；不要让整个世界无因恒亮。

## 质量门

确认前中后景可区分；至少一个对象提供可靠尺度；事件有传播路径；群体不是复制粘贴；摄影机扩大了空间而非遮蔽因果；余波能解释最终画面状态。
