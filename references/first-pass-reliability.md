# 首轮生成可靠性

在交付任何复刻视频的最终提示词前执行。本规范不追求消灭所有采样随机性，而是提前清除会稳定导致错误的歧义、素材冲突和时间漂移，减少必须等成片出来后才发现的问题。

## 一、先建立关键状态账本

只为真正决定成败的姿态、接触、状态切换和终态建立账本。每个关键状态至少回答：

| 字段 | 必须明确的内容 |
|---|---|
| 到达时间 | 何时开始、何时到位、是否为不可延长的硬切点 |
| 固定锚点 | 哪些头、肩、髋、手、脚或物体基本不动 |
| 唯一主变化 | 这一段主要改变哪个关节、物体或画面状态 |
| 屏幕几何 | `x% / y%`、占比、方向、前后层级、遮挡和是否出画 |
| 拓扑关系 | 肢体或物体从哪里连接到哪里，转折点在哪里，哪一段朝哪个方向 |
| 速度曲线 | 匀速、先慢后快、突然释放、减速或定格 |
| 结束保持 | 保持多久；核心哪些部位锁死；哪些次级元素仍可衰减 |

不要只写“屈膝、抬腿、后仰、黑化、眨眼”。这些词不决定模型应把膝盖放在哪里、黑到什么程度、闭眼持续多久。

## 二、用屏幕拓扑替代模糊动作词

角度只描述局部夹角，不能替代屏幕位置和连接关系。强透视、遮挡或贴近镜头的肢体必须同时描述：

- 关节的屏幕坐标或区域，以及它随时间向哪个方向移动。
- 上一段肢体从哪个锚点连接到该关节。
- 下一段肢体从关节向哪个方向折返、延伸或出画。
- 哪一段在前景、哪一段被遮挡、轮廓占画面多少。
- 是“膝盖靠近胸口”还是“膝盖远离躯干并向右边界移动”；两者即使关节角相同，画面完全不同。

对每个高风险姿态做“骨架口述测试”：遮住人物纹理后，仅凭文字能否画出头—肩—髋—膝—踝—脚尖的折线。如果不能，继续补几何，不要用更多形容词代替。

## 三、动作必须描述路径，不只描述关键帧

故事板只给出离散状态，视频模型仍会自行猜测中间运动。每段至少写：

`起始状态 → 固定锚点 → 主关节/物体轨迹 → 速度变化 → 到达状态 → 保持`

连续蓄力或变形还要检查单调性：例如膝盖应逐格向右、小腿逐格向左铺开、弯曲逐格加深。后一个状态不得在未释放前反向变直。图片和文字必须表达同一单调趋势。

禁止项必须同时给正向替代：不要只写“禁止直立”，还要写“身体悬空斜躺，头在右上、骨盆在左下、双脚无支撑”。

## 四、区分持续状态与瞬态事件

模型容易把被抽到的一帧当成整段状态。必须明确：

- 眨眼、闪白、负片、抽帧、微震属于瞬态，写开始时间和最大持续时长，例如“闭眼不超过0.06秒，立即重新睁开”。
- 蓄力姿势、持续接触、纯黑剪影、终态定格属于持续状态，写进入时点、退出时点和保持条件。
- 故事板中偶然闭眼、运动模糊或遮挡，不得自动解释为角色持续闭眼、缺肢或静止。

## 五、状态切换要写成离散视觉操作

“变暗、黑化、冲击感、粒子化”容易被弱化。需要按可见结果写：

- 材质/颜色切换：是降低亮度，还是用完全不透明遮罩替换；必要时写 `RGB(0,0,0)`、不保留肤色/服装色/纹理/高光，以及允许保留的轮廓光。
- 人物显现：粒子先出现在哪里，先勾出哪些轮廓，身体从哪一部分到哪一部分凝实，何时才成为完整人物；粒子不是背景装饰。
- 冲击后期：触发帧、白底或黑底、剪影、裂线、负片、抽帧的顺序和总时长。
- 环境切换：旧背景何时完全退出，新背景哪些元素保留；不要只写情绪颜色。

对每个状态切换做“残留检查”：列出转换后必须消失的旧颜色、材质、背景或姿势。

## 六、素材职责与冲突优先级

在提示词开头定义唯一职责：

- 角色图：身份、脸、体型、服装。
- 深度故事板：位置、尺度、遮挡、深度、肢体轮廓和动作相位。
- 彩色故事板：经深度校准后的构图、动作相位、环境阶段、光色与VFX预览。
- 文字：连续动作、动力、速度曲线、表情、状态转换、运镜、声音和所有图片未能明确表达的内容。

为冲突项写优先级。角色图不能把站立姿势带入动作；彩色故事板不能覆盖角色身份和服装；故事板中的肢体瑕疵不能覆盖文字几何。通常不要同时上传深度板和彩色板争夺同一职责。

## 七、故事板发布前验收

深度板或彩色板进入视频输入前必须逐格检查：

1. 总格数、编号、阅读顺序和分辨率正确。
2. 人眼能区分头、躯干、双臂、双腿、接触对象和前后层级。
3. 每个关键分格符合状态账本；尤其检查动作趋势是否单调、接触是否先于受击、终态是否符合轴线和保持要求。
4. 相邻分格没有语义反转，例如本应继续屈膝却突然直腿、本应纯黑却重新出现服装色。
5. 角色、服装、场景和VFX没有互相覆盖错误。
6. 彩色板必须让用户先验收；不合格时先修板，不拿错误故事板试视频。

故事板过密而单格看不清时，减少格数、放大关键格或拆成局部序列。不能把“有很多帧”当成“模型一定能理解”。

## 八、时间预算与硬切点

先以源视频元数据和可见事件确定真实时间，再映射到目标时长。不要让一个镜头因为描述较多就自动占据更多秒数。

- 为每个镜头写开始/结束；容易拖长的特写或蓄力写“必须在X秒硬切/退出”。
- 接触、冲击帧、背景切换和释放的时间必须互不冲突。
- 生成时长与原片不同时，按动作节奏比例映射，而不是直接沿用原时间戳。
- 5秒复杂短片通常将中文提示词控制在约1000–2500字符，必要时接近3000；优先保留空间几何、动作路径、时间、状态切换和终态，删除重复风格词。

## 九、交付前的无图模拟

隐藏所有故事板，只读最终文字，模拟一次视频：

1. 第一帧每个人在哪里、身体是否站立或悬空？
2. 每段是谁先动，哪个部位保持不动，哪个部位沿什么路径变化？
3. 接触前是否有空隙，接触点在哪里，谁先产生反应？
4. 粒子、颜色、材质、背景和后期状态何时进入、何时退出？
5. 瞬态事件持续多久，持续状态保持多久？
6. 最后一帧的身体轴线、屏幕位置和允许继续运动的元素是什么？

任一答案只能靠“参考图片/按故事板”才能得到，说明文字不自足，必须补写。目标不是让文字重复每个像素，而是即使模型只粗略读取密集故事板，仍能执行正确动作。

## 十、反向误读检查

交付前为每个高风险句子写出模型最可能的错误解释，再确认提示词已排除它：

- “抬腿”可能被理解为站立抬腿。
- “深度屈膝”可能被理解为膝盖贴胸的小抱膝，而不是膝盖远离身体。
- “闭眼帧”可能被理解为整段闭眼。
- “黑化”可能只是降低亮度而保留彩色材质。
- “对应01—05”可能被理解为静态翻页或随机插值。

只有正向几何、时长、残留清除和优先级都明确后，才交付最终提示词。
