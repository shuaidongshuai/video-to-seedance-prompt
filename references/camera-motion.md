# 运镜判读

将摄影机运动与主体、环境和剪辑运动分开。只写画面支持的轨迹，不臆造焦距、光圈、设备或稳定器。

## 三步判读

1. 找相对稳定的背景线、地平线和遮挡关系。
2. 比较主体在画框中的大小、位置和透视变化。
3. 检查变化是否连续，还是由切镜、数码裁切、速度变化或画面旋转造成。

## 方向性运镜的证据门

只要最终提示词要明确写出“推近、拉远、横移、环绕、升降”等方向，就不能只依据一张起始帧和一张结束帧。先检查覆盖整个镜头的连续时间序列；细微运镜、短镜头或人物面部特写应在歧义窗口加密抽帧，直到能够确认主体占比变化是否单调、背景显露与透视是否同步、人物自身是否前后移动。

- 主体占比连续减小、画面逐步露出更多身体与背景，且主体自身位置相对稳定，支持“摄影机后拉/拉远感”。
- 主体占比连续增大、背景范围收窄，且主体自身位置相对稳定，支持“摄影机前推/推近感”。
- 只有两三张稀疏帧、主体同时移动或背景缺少稳定参照时，方向证据不足；继续加密取证，或只写“主体在画面中连续变大/变小”，不要强制选择推或拉。
- 发现方向与初步判断相反时，应重新检查该镜头相邻的表演、构图终点和切镜，不只机械替换一个运镜词。

## 常见证据

- `pan / tilt`：机位位置大致不变，视线水平或垂直旋转，透视变化有限。
- `dolly in/out`：主体尺度与前后景相对位移同时变化，透视发生改变。
- `zoom`：主体变大/变小但透视压缩关系相对稳定；证据不足时写“推近感/拉远感”。
- `tracking`：摄影机随主体平移，主体在画框位置相对稳定，背景横向流动。
- `orbit / arc`：主体周围可见面逐渐改变，背景相对主体旋转。
- `crane / rise / descend`：机位高度连续变化，俯仰和遮挡层级改变。
- `handheld`：非周期的小幅位移与旋转；不要把命中瞬间的一次震动扩写成全程手持。
- `whip pan`：快速方向性旋转、明显运动模糊，之后落到新构图。
- `roll`：地平线连续旋转。
- `POV`：机位被叙事明确绑定到角色视点；低机位或贴身跟拍本身不等于 POV。

## 相对主体描述

优先写“摄影机位于谁的哪一侧、以何高度、沿什么路径、何时改变速度、最终落到什么构图”。例如：

```text
摄影机保持腰部高度，在角色 A 左后方并行跟拍；A 加速时同步前移，接触瞬间出现一次短促微震，随后横移至 B 侧面捕捉后退反应。
```

## 镜头与剪辑分界

突然改变视角、主体大小或画面方向时先判断是否切镜。闪白、遮挡转场、动作匹配剪辑、速度坡度和数码推近单独记在 `edit_effect`，不能全部写成实体摄影机运动。

## 不确定性

无法区分镜头推近与主体接近时，写可观察结果：“主体在画面中快速变大，背景透视变化不明确”，并标为低置信度。提示词编译时选择不会强迫错误机制的表达。

## 运镜链检查

对每个镜头写：起始机位/景别 → 路径 → 速度变化 → 动作峰值时的响应 → 结束构图。相邻镜头必须说明切换方式；运镜数量服从参考，不为“电影感”额外增加无意义旋转、抖动或变焦。
